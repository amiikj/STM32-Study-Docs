#STM32F103 嵌入式学习资料（持续更新）

##项目简介
本项目为大一自学B站的江协视频时做的学习笔记(Word)与部分拓展项目的练习，内容目前包含到从GPIO的基础控制到SPI协议通讯部分。

##硬件与软件环境
-**主控芯片**：STM32F103C8T6
-**开发环境**：Keil MDK 5(标准库)
-**调试工具**：ST-Link,Slogic Combo 8,数字万用表
-**传感器**：参考江协配套的传感器组件


##项目目录
-‘01_GPIO’:LED点灯，LED流水灯，蜂鸣器发声，按钮输入，光敏传感器与蜂鸣器，OLED,对射式红外传感器计次，旋转编码器计次
-‘02_TIM_PWM’:LED呼吸灯，PWM与舵机，PWM与直流电机，PWM输入捕获，编码器接口测速
-‘03_AD’:AD单通道，AD多通道
-‘04_DMA’DMA数据搬运
-‘05_USART’:串口发送，串口接收
-‘06_I2C’:软件I2C读写MPU6050,硬件I2C读写MOU6050
-‘07_SPI’:软件SPI读写W25Q64,硬件SPI读写W25Q64

##学习笔记的格式
-电路图
-项目实施
    -代码编写
    -常见问题
-成果展示(没上传视频，所以看不了)
